ตารางเวรผู้ช่วยเหลือคนไข้

จัดเวรอัตโนมัติตามเงื่อนไขรายบุคคล · แก้ไขรายช่องได้

ภาพรวมทั้งเดือน

ช = เช้า 08.00–16.00 · บ = บ่าย 16.00–24.00 · ด = ดึก 00.00–08.00 ของวันที่นั้น · คอลัมน์สีส้ม = วันหยุด/นักขัตฤกษ์

ตรวจสอบเงื่อนไข

    ตารางรายวัน

    เปลี่ยนชื่อในช่องได้เลย ช่องที่แก้เองจะถูกล็อก 🔒 และคงไว้เมื่อกดจัดเวรอัตโนมัติใหม่ ช่องสีส้มคือขัดเงื่อนไข (ชี้เพื่อดูเหตุผล)

    ความต้องการรายวัน

    คลิกช่องเพื่อเลือก ขออยู่เวร / ขอเวรเช้า-บ่าย-ดึก / ไม่อยู่เวร / ลา · คลิกหัววันที่เพื่อกำหนดหรือยกเลิกวันนักขัตฤกษ์ (นข) แล้วกดจัดเวรอัตโนมัติอีกครั้ง

    อยู่ ขออยู่เวร (เวรใดก็ได้) ช / บ / ด ขออยู่เวรนั้น ✕ ไม่อยู่เวร ลา ลา

    วันนักขัตฤกษ์ตั้งต้นมาจากรายการที่ตั้งไว้ในโปรแกรม (วันหยุดตามจันทรคติและวันหยุดชดเชยควรตรวจทานกับประกาศของปีนั้น)

    สรุปจำนวนเวร

    ณัฐสุรางค์นับเวรตามลำดับวันที่ เวรแรก ๆ เท่ากับจำนวนวันทำการของเดือน (หักวันลาในวันทำการ) เป็นเวรหลัก ที่เหลือเป็น OT · คนอื่นนับเป็น OT ทั้งหมด

    เงื่อนไขทั่วไป

    นับเวรต่อเนื่องตามเวลา เช่น บ่าย→ดึกวันถัดไป, เช้า→บ่าย→ดึก, ดึก→เช้า→บ่าย นับเป็น 3 เวรติดกัน

    เงื่อนไขรายบุคคล

    ติ๊กช่องที่ อยู่ได้ · คอลัมน์ นข = อนุญาตเพิ่มในวันนักขัตฤกษ์ · เป้าหมายเว้นว่าง = รับส่วนที่เหลือ · เพดาน 0 = ไม่จำกัด · ช่องเวรวันหยุด/เช้าวันหยุดเว้นว่าง = ไม่จำกัด (วันหยุด = เสาร์ อาทิตย์ นักขัตฤกษ์)
